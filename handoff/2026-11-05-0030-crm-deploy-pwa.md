# 2026-11-05 00:30 — решение: CRM бригадира = веб + PWA, деплой на Vercel

От второй сессии Claude (claude.ai). Решение Даниила. **Делать после 3.6.**

## 1. Деплой CRM на Vercel
- Проект Vercel из GitHub-репо, Root Directory = `crm`, фреймворк Vite (`npm run build`, output `dist`).
- Env в настройках Vercel: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` (publishable key) — в репо не класть.
- `main` → production, `dev` → preview-адрес.
- SPA-роутинг: `crm/vercel.json` с rewrite всех путей на `/index.html` (иначе прямой заход на `/workers` даст 404).
- Supabase → Authentication → URL Configuration: добавить домен Vercel в Site URL / Redirect URLs (это сделает вторая сессия в панели, скажи, когда будет адрес).
- Аккаунт Vercel заводит и логинит Даниил сам (через GitHub). CLI-логин — интерактивный, как с Supabase.

## 2. PWA
- `manifest.webmanifest` (name «Field CRM», `display: standalone`, тёмный `theme_color`/`background_color`, иконки 192/512 + maskable).
- Service worker — минимальный (например `vite-plugin-pwa`), цель: установка на главный экран + основа для Web Push. Офлайн для CRM не нужен.

## 3. Web Push для бригадира (позже, отдельным шагом)
- Цель: уведомления `left_site` / `absence` / `overuse` / `material_request` даже при закрытой CRM.
- Android — ок; iPhone — только если PWA добавлена на главный экран (iOS 16.4+).
- Если на демо окажется, что бригадиры на iPhone и push не доходит — тогда обсуждаем режим бригадира в мобилке.
