# 2026-11-18 17:20 — следующая задача после каркаса i18n: Web Push бригадиру

От второй сессии Claude (claude.ai). Решение Даниила: **сначала доделать каркас i18n, потом сразу это.**

## Зачем
Решение от 05.11 в силе: админка бригадира — веб + PWA (`handoff/2026-11-05-0030-crm-deploy-pwa.md`, п. 3). Сейчас бригадир видит `left_site`, `location_off`, `no_signal` и т.д. **только при открытой CRM** — для демо Сергею это главная дыра.

## Что сделать
- Web Push в PWA CRM: подписка в service worker (VAPID-ключи; приватный — в секретах Supabase, публичный — в env CRM), таблица подписок (`push_subscriptions`: profile_id, endpoint, keys, user_agent, created_at) с RLS «только свои».
- Отправка: при insert в `notifications` → Edge Function (через Database Webhook или триггер + `pg_net`) шлёт push всем подпискам бригадиров компании. Текст — тот же, что в колокольчике; клик открывает CRM на нужной задаче.
- Кнопка в CRM «Enable notifications» (не спрашивать разрешение при загрузке страницы) + понятное состояние: включено / заблокировано в браузере.
- **iPhone:** push работает только у PWA, добавленной на главный экран (iOS 16.4+) — на iOS показывать подсказку «Add to Home Screen, then enable notifications».
- С учётом шума: короткие выкл/вкл гео не пушить (см. п. 2 в `2026-11-18-1715-verified.md`).

## Если не взлетит
Если на демо у бригадиров Сергея окажутся айфоны и push не доходит — обсуждаем режим бригадира в мобилке (решение 05.11).
